Failed load of a gateway-backed surface (charte §08). Red-tinted, names the HTTP reality, and always offers a retry.

```jsx
<ErrorState request="GET /api/connectors · 504 · req_8f2c…"
  action={<Button size="sm" variant="secondary">Réessayer</Button>}>
  La passerelle n'a pas répondu (504). Vos données locales restent affichées.
</ErrorState>
```

A disabled module is NOT an error — use EmptyState (« Module désactivé · dégradation propre »).
